# 授权行情研究源来源格式

支持 FAST 1.1 stop-bit integer、ASCII string、decimal、sequence，模板操作符 none/constant/default/copy/increment/delta，可选字段遵守 nullable 编码；presence map 最高位为终止位，位从高到低消费。模板id可沿用，dictionary 支持 global/template/type 及 key。feed-manifest 将原始字节切为来源 frame，sequence 缺口使依赖字典失效，resets 列出来源明确重置帧；不从输出数值猜测重置。每条记录保存 session、sequence、templateId 和 raw offset，无法解码保留原文并报告 blocked。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://www.fixtrading.org/standards/fast-online/。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
