# 授权行情研究源来源格式

支持 FAST 1.1 stop-bit integer（带符号与无符号）、nullable 整数（单字节 0x80 表示 null，其余按符号量映射还原）、ASCII string、decimal（保留指数与尾数分量）、sequence，模板操作符 none/constant/default/copy/increment/delta，可选字段遵守 nullable 编码；presence map 每字节最高位为终止位（不作为数据位消费），其余 7 位从高到低消费，跨字节继续按高位优先。模板 id 占用 presence map 第一个位：为 1 时流中携带 id，为 0 时沿用上一条消息的模板，没有可沿用模板即报告 TEMPLATE_CONTEXT。操作符的 presence map 占位规则：none/constant 仅可选字段占位；default/copy/increment/delta 同样仅可选字段占位，强制字段始终在流中。dictionary 支持 global/template/type 及 key，key 与字段名共同构成存储键，template 作用域按模板隔离、type 作用域按字段类型隔离。feed-manifest 将原始字节切为来源 frame，sequence 缺口使依赖字典失效，resets 列出来源明确重置帧；不从输出数值猜测重置。每条记录保存 session、sequence、templateId 和 raw offset，无法解码保留原文并报告 blocked。

## 状态纪律

- 不把每条消息当作独立编码：copy/increment/delta 等操作符依赖跨消息字典，解码按模板字段顺序与 presence map 位逐字段进行。
- 显式重置：manifest `resets` 中声明的帧在解码前清空全部字典作用域，这是缺口后恢复解释依据的唯一合法途径。
- 源流缺口：帧序号不连续即标记字典解释依据失效；在合法重置出现前，后续帧不再发布依赖状态的字段，只保留原文并标记 blocked，绝不沿用陈旧值凑出连续行情。
- 帧内无法解释（未知模板、未承诺类型或操作符、presence map 耗尽、字节截断、解码后仍有无法解释的剩余字节）同样使该帧及后续帧进入 blocked，原文与偏移仍完整保留。
- 未在本文件承诺的模板扩展保留原文并明确不支持，不能假装完整解析。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://www.fixtrading.org/standards/fast-online/。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
